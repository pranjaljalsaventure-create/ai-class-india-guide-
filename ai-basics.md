# Artificial Intelligence Basics

Artificial Intelligence, commonly called AI, refers to technologies that enable computer systems to perform tasks that normally require aspects of human intelligence.

These tasks can include recognising patterns, understanding language, making predictions, analysing information, and generating content.

## Important AI Concepts

### Machine Learning

Machine learning allows computer systems to identify patterns from data and use those patterns to make predictions or decisions.

### Computer Vision

Computer vision focuses on enabling computers to interpret information from images and video.

### Natural Language Processing

Natural language processing helps computer systems work with human language in applications such as chatbots, translation, and text analysis.

### Generative AI

Generative AI systems can produce content such as text, images, audio, or computer code based on user instructions.

## Why Learn AI Fundamentals?

Understanding the fundamentals helps students move beyond simply using AI tools. They can begin to understand how AI systems work, what data means, and why AI outputs need to be evaluated carefully.

A strong foundation is useful before progressing to advanced AI and machine learning topics.
